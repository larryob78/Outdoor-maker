# Napkin Outdoor Maker

One idea, every outdoor format, in situ.

## MVP
Upload a key visual, generate six format-aware layouts, preview in situ, export PNGs and a presentation. Next phases: image model art direction, perspective-aware compositing, animated DOOH and validated production specs.

## Development
Use Codex to build a React/TypeScript application with tests. Experiment with DeepSeek's new creator tooling only after confirming the official package and documentation. Never expose API keys client-side.
